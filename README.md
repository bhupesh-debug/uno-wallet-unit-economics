# Unit Economics of One Uno User

**For:** Uno Wallet — AI Business Analyst (YC P26 startup, AI iPhone wallet)
**Author:** Bhupesh Chandra Dimri
**Stack:** Python 3, pandas, NumPy, scikit-learn, matplotlib

## One-liner

A reproducible LTV/CAC engine for a two-person startup's most important question —
what is one user worth, what does one user cost, and which assumption decides
the answer? Built on synthetic data with every input labelled [ASSUMPTION].

## ⚠️ Synthetic data — read first

Uno Wallet has published no acquisition costs, activation rates, retention,
spend, or revenue figures. **Every input in this project is a labelled
[ASSUMPTION], not a fact about Uno Wallet.** The point of the project is the
machinery — the LTV engine, the sensitivity analysis, the break-even math —
and the honest finding that the answer is fragile. Nothing here is a claim
about Uno Wallet's real business.

## Headline findings (base [ASSUMPTION]s)

- Blended **LTV:CAC 1.02** (LTV $19.19 vs CAC $18.90) — essentially break-even.
- **Payback ~20.1 months** — long for a startup that needs the cash back.
- **Break-even retention 0.817 vs assumed 0.82** — the model lives or dies on
  a 0.3-point margin in monthly retention.
- **Sensitivity ranking:** retention dominates (spread 0.58), then CAC (0.42),
  revenue per active user (0.41), activation (0.41); discount rate barely matters.
- **Channels split hard:** organic 5.55 and referral 2.94 pay; paid search 0.35
  and paid social 0.33 never pay back at base assumptions (break-even retention
  ~0.94–0.95).
- **Three levers:** retention (+5pp → +35.7% LTV:CAC), revenue per active user,
  activation.
- **Honest checks:** empirical cohort LTV:CAC is 1.18, 14.4% above the
  closed-form 1.03 — user heterogeneity fattens the tail, so a single
  exponential retention fit overstates retention (fitted 0.884 vs assumed
  0.82, RMSE 0.079). The activation classifier (logistic regression) scores
  AUC 0.672 vs a 0.500 naive baseline.

## How to run

```bash
python run_all.py            # data -> LTV engine -> sensitivity -> charts + reports/metrics.json
python -m tests.test_all     # test suite (prints a runtime "N passed" line)
python build_docs.py         # 10-page report + 10-slide deck PDFs
```

## Key assumptions ([ASSUMPTION] — not Uno Wallet facts)

| Input | Value |
|---|---|
| Channel mix / CAC | organic $4, referral $8, campus $18, paid social $38, paid search $42 |
| Activation rate | organic 68%, referral 72%, campus 60%, paid search 45%, paid social 38% |
| Monthly retention | 0.82 (per-user spread ±0.06) |
| Mean monthly spend | $1,150 |
| Earn rate / Uno take | 2.1% rewards, Uno keeps 30% |
| Servicing cost | $1.10 / active user / month |
| Discount rate | 1% / month |

Net revenue per active user per month: $1,150 × 2.1% × 30% − $1.10 = **$6.15**.
